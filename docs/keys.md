# Keys & hotkeys

**Global:** `[` / `]` previous / next tab &middot; `1`–`5` jump to a tab &middot;
`c` open the connection dialog &middot; `q` or `ctrl+c` quit.

**Browser:** `/` fuzzy search &middot; `f` cycle type filter (counter / gauge /
string / …) &middot; `s` cycle sort field, `S` toggle direction &middot; `enter`
drill into the selected subtree &middot; `backspace` go up one level &middot;
`r` re-walk &middot; `g` send the selected object to the Graph tab.

**Graph:** `o` fuzzy object picker &middot; `t` cycle chart type (line / bars /
sparkline / gauge / big-number / heatmap) &middot; `d` toggle raw vs
per-second rate for counters &middot; `x` clear history.

**Discovery:** `tab` move between fields &middot; `enter` start the sweep &middot;
`esc` cancel a running sweep &middot; `enter` on a result row connects to it.

**Settings:** `up` / `down` select a row &middot; `left` / `right` adjust &middot;
`s` save to disk.
